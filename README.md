# Krishna Pratap Singh — Portfolio

A living, mouse-reactive portfolio site. **Cosmic Intensity** theme (deep-space black → violet
→ cyan), a reactive canvas particle "energy core" in the hero, and site-wide magnetic cursor /
spotlight / mouse-tilt effects. Built for speed: **~34 KB JS / ~21 KB CSS**.

**Stack:** [Vite](https://vitejs.dev) + vanilla JS (ES modules) + [Lenis](https://lenis.darkroom.engineering)
smooth scroll. No framework. All animations are perf-gated (pause off-screen / when the tab is
hidden) and respect `prefers-reduced-motion`.

---

## Prerequisites

- **[Node.js](https://nodejs.org) 18 or newer** (includes `npm`). Check with `node -v`.

## Run it locally

```bash
npm install     # first time only — installs dependencies into node_modules/
npm run dev     # start the dev server
```

Then open **http://localhost:5173**. Edits to any file hot-reload the browser instantly.

> **Why a server?** The site uses ES-module `import`s and npm packages (like `lenis`) that a
> browser can't resolve on its own — and browsers refuse to load modules over `file://`. The Vite
> dev server translates the modern source into something the browser runs live. This is a
> **build-time** convenience, *not* a runtime requirement — see below.

## Build for production

```bash
npm run build     # bundles everything into a static dist/ folder
npm run preview   # optional: preview the built dist/ at http://localhost:4173
```

`dist/` is **plain static HTML/CSS/JS** — no Node server needed to host it. To go live, see
**[DEPLOY.md](DEPLOY.md)**.

## Project structure

```
Potfolio_website/
├── index.html              # markup for every section (nav, hero, about, skills, work, reviews, contact)
├── vite.config.js          # dev server + build config
├── public/                 # static assets served as-is (résumé PDF lives here)
├── src/
│   ├── main.js             # boot: render content, smooth scroll, reveals, interactions
│   ├── js/
│   │   ├── data/           # content you edit: skills.js, projects.js, reviews.js
│   │   └── lib/            # particles.js (energy core), cursor.js (cursor/tilt/magnetic)
│   └── styles/             # tokens.css (design tokens) · base.css (reset) · main.css (components)
└── dist/                   # generated by `npm run build` — do not edit by hand
```

## Editing content

- **Skills** → `src/js/data/skills.js`
- **Projects** → `src/js/data/projects.js` (fill in each project's `liveUrl` / `codeUrl`)
- **Reviews** → `src/js/data/reviews.js` *(currently placeholders — swap for real quotes)*
- **Colors / fonts / spacing** → `src/styles/tokens.css`
- **Résumé** → replace the PDF in `public/`

## npm scripts at a glance

| Command | What it does | When |
|---|---|---|
| `npm run dev` | Dev server at `localhost:5173` with hot reload | While editing |
| `npm run build` | Bundle into static `dist/` | Before deploying |
| `npm run preview` | Preview the built `dist/` locally | Sanity-check the build |

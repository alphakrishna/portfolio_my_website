\# Animation Enhancer Instructions

Review the target file or code section. Upgrade all basic or static CSS transitions to use premium motion design principles:

\- Replace linear or default transitions with custom cubic-beziers like `cubic-bezier(0.16, 1, 0.3, 1)` for ultra-smooth easing.

\- Apply subtle staggered entry delays to children components (lists, cards, grid items).

\- Ensure all interactive elements (hover, active, focus states) have fluid micro-interactions.

\- Wrap animations in `@media (prefers-reduced-motion: no-preference)` to keep it accessible.
